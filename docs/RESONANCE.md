# RESONANCE — дизайн 2026-11-26

## Утверждённое направление

Пошаговая вычислительная песочница, не таймер и не ритм-игра. Игрок проектирует инфраструктуру, которая продолжает работать между ходами. Цель — не только достижение заданного состояния поля, но и удовольствие от строительства системы.

### Поле
- Два независимых слоя: материя (0 CHAOS, 1 TABLE, 2 CRYSTALL) и операторные поля. VOID — особое состояние, не четвёртая обычная фаза материи.
- Нормальная мутация 0→1→2→0; обратная 0→2→1→0.
- SW проходит все столбцы слева направо; вычисление реально последовательное, не предварительный расчёт с последующей анимацией. Следующий столбец может учитывать уже обновлённый левый. В качестве исходного кандидата генератора — два различных адреса мутации на столбец; точный алгоритм ещё подлежит утверждению.
- Только RUNTIME среди обычных операторов блокирует автономную мутацию. Наличие любого другого оператора само по себе не защищает материю.
- VOID не мутирует и не участвует в вычислениях.
- Размер поля существенно растёт по сюжету; конкретные размеры не определены.

### Ход
- Все восемь операторов доступны постоянно; каждый можно применить не более одного раза за ход. Колоды операторов нет.
- Игрок выбирает оператор и карту числового аргумента из руки, размещает его по соответствующим геометрическим правилам.
- Стоимость PU = аргумент × коэффициент оператора. Не площадь и не длина маршрута. Коэффициенты TBD.
- Исходный бюджет хода 100 PU — рабочая отправная точка из обсуждения, не баланс финальной игры. CYCLE производит PU, точная экономика TBD.
- Игрок может завершить ход раньше и запустить SW. Неиспользованный PU рассеивается по базовому правилу; возможные исключения TBD.
- После SW начинается новый ход; операторы вновь доступны.
- Ошибочное размещение не должно тратить ресурс/карту (предлагаемый инвариант QA).

### Колода
36 карт активной колоды. Начальный состав: по 6 экземпляров номиналов 1, 2, 3, 4, 5, 6. Коллекция расширяется сюжетными наградами, помощь персонажу может приносить карту. Планируемый диапазон 1–22. Добавление карты требует убрать другую, размер колоды остаётся 36. Никаких платных случайных наград.
Большие числа не являются универсальным улучшением: стоимость линейна, геометрия и эффективность зависят от оператора. Малые номиналы особенно ценны для точного RUNTIME; ENCODE/LOGIC могут иметь обратную эффективность (гипотеза). Размер руки, правила добора/сброса/перетасовки TBD.

### Задачи
Ранние эксперименты использовали целевой рисунок; победа должна зависеть от заданного условия, а не обязательного закрепления всех клеток. Возможны задачи на свойства, поведение, устойчивость инфраструктуры. Конкретные типы миссий TBD. Игроку должно быть интересно строить даже без немедленного достижения цели.

# Разработка

## Направление
Godot — предпочтительный движок, версия и конкретный рендерер пока не утверждены. Цель: бесплатная игра с возможностью Web Export на GitHub Pages и нативными сборками. Проверить совместимость веб-экспорта до наращивания контента. Никакого обязательного сервера, аккаунтов или сетевой экономики. Локальные сохранения; экспорт/импорт JSON как предлагаемая защита от очистки браузера.

## Предлагаемая архитектура
- Чистое вычислительное ядро RESONANCE: состояние материи, операторные поля, граф связей, колода, PU, команды, SW, RNG. Не зависит от сцены и анимаций.
- UI: отображение состояния, интерактивное рисование CONNECT/RUNTIME, предварительный просмотр, журнал; анимация показывает фактические изменения ядра.
- VN: сюжетные узлы, выборы, награды, переходы к игровым операциям.
- Сохранения: версия схемы, сюжетный прогресс, коллекция/колода, состояние партии, seed и состояние генератора, журнал действий. Проверить воспроизводимость после загрузки.
- Контент и звук: загружать по необходимости, учитывать размер веб-сборки и постоянство голосов.

## Роли
Автор определяет дизайн и принимает решения, выполняет ручной QA. ChatGPT помогает проектировать, документировать, проверять исходники и тестировать доступные сборки. DeepSeek с локальным Godot MCP реализует согласованные задачи. Codex не является зависимостью процесса.

## Порядок работы
1. Уточнить минимальный набор правил для следующего прототипа и записать решение.
2. Реализовать только утверждённый объём, выделить тестируемое ядро.
3. Предоставить исходники, инструкции запуска, тестовые сценарии и по возможности Web Export.
4. Независимая проверка, баг-репорты, исправления, обновление документации.
5. После стабилизации базовых операторов расширять синтезы и контент.

Нативный и веб-запуск в среде ChatGPT пока не проверены. Наличие доступа к репозиторию не означает доступ к локальному MCP или компьютеру автора. Не считать успешным тест, который не запускался. Не добавлять лицензии, секреты, платные сервисы или чужие ресурсы без согласования.

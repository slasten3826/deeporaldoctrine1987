# QA — проект тестового плана

Статус: сценарии для будущей реализации, ни один тест ещё не выполнен. Неопределённые механики не получают произвольного ожидаемого результата.

## Плейтесты
Проверять разные стратегии: инфраструктурная экономика, минимальное вмешательство, эксперименты с синтезами. Следить за ценностью малых номиналов, удобством маршрутизации, читаемостью физического поля и области действия, возможностью предсказать каскадный VOID, интересом к строительству без цели миссии.

## Баг-репорт
Версия/коммит, платформа, seed, исходное состояние, последовательность действий, ожидаемое и фактическое поведение, скриншот/лог, частота воспроизведения. При неопределённой спецификации оформлять вопрос дизайна, а не баг.

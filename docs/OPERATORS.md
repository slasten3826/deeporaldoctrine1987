# Операторы и аргументы

Аргумент n — целое число 1–22. Каждый оператор интерпретирует его самостоятельно. Цена = n × k(op). Коэффициенты не определены. Цвета ниже — унаследованные ориентиры Packet, не утверждённый UI.

| Оператор | Цвет | Функция | Геометрия |
|---|---|---|---|
| ☰ CONNECT | жёлтый | связывает целые поля | рисуемый ортогональный маршрут, n прямых сегментов максимум |
| ☷ DISSOLVE | фиолетовый | удаляет операторные поля, очищает VOID | TBD |
| ☴ OBSERVE | белый | раскрывает будущие мутации SW | одна физическая клетка, охват зависит от n |
| ☵ ENCODE | синий | TBD, вероятно работа с картами | TBD |
| ☳ CHOOSE | красный | выбирает нормальную или обратную мутацию | TBD |
| ☲ CYCLE | оранжевый | производит PU | квадрат n×n, занимает все клетки |
| ☶ LOGIC | зелёный | TBD, вероятно работа с правилами карт | TBD |
| ☱ RUNTIME | серый | фиксирует материю | n клеток, связных по сторонам |

## ☰ CONNECT
Игрок сам рисует линию по клеткам. n=1 — прямая любой допустимой длины, не диагональ; n=2 — до одного поворота; n=3 — до двух и т.д. Принято толкование n−1 поворотов на основании примеров; оговорка про «5 изгибов» требует уточнения, если автор имел иной смысл. Длина сама по себе не влияет на цену. Пересечения объединяют сети, поэтому маршрутизация критична. Собственной вычислительной функции нет. Условия самопересечения и касания TBD.

## ☱ RUNTIME
n клеток, игрок выбирает любую связную конфигурацию через стороны, не диагонали. Например n=4 может образовывать квадрат, линию, T или L. Единственный обычный оператор, блокирующий естественную мутацию материи. Сохранение PU не утверждено.

## ☴ OBSERVE
Физически всегда одна клетка, только она участвует в синтезе. n=1 показывает свою клетку; n=2 — крест из 5; n=3 — 3×3 (9); n=4 — четырёхлучевая звезда, точная маска TBD. 13 клеток и формула 4n−3 — возможная гипотеза, не утверждённый закон. Охват должен расти медленнее CYCLE на больших n. Не блокирует SW. Маркеры будущих мутаций вне охвата скрыты. Как прогноз согласуется с последовательным SW, TBD.

## ☲ CYCLE
n=1: 1 клетка; n=2: 4; n=3: 9; n=4: 16; n=22: 484. Все клетки физически заняты оператором. Генерирует PU. Момент начисления, объём и ограничения не определены. Большая площадь повышает риск вовлечения в VOID.

## ☳ CHOOSE
При размещении выбирается нормальное либо обратное направление мутации. Нормальный режим не отменяет мутацию. Оператор остаётся на поле даже в нормальном режиме, например для дальнейшего синтеза. Геометрия и область действия TBD.

## ☷ DISSOLVE
Удаляет другие операторные поля, включая CONNECT. Только DISSOLVE способен очистить VOID. Удалённые операторы и прежнее состояние материи не восстанавливаются автоматически. Сам DISSOLVE исчезает через 1 или 2 хода (точная длительность TBD). Что именно происходит при частичном попадании в поле и какое состояние материи появляется после очистки VOID, TBD.

## ☵ ENCODE / ☶ LOGIC
Функции не утверждены. Направление поиска — работа с рукой, аргументами, правилами их применения или добором. Возможна обратная зависимость эффективности от n, чтобы малые карты имели самостоятельную ценность. Не реализовывать конкретный эффект без согласования.

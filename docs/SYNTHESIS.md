# Синтез, CONNECT и VOID

## Правило
CONNECT — проводник, связывающий целые операторные поля, а не только отдельные контактные клетки. Сами клетки CONNECT сохраняют свою идентичность. CONNECT и DISSOLVE исключены из набора вычислительных операторов для синтеза.

Шесть участвующих типов: OBSERVE, ENCODE, CHOOSE, CYCLE, LOGIC, RUNTIME.
Два различных типа образуют один неупорядоченный синтез: C(6,2)=15 комбинаций. Самосинтеза нет. Конкретные эффекты всех 15 TBD.

Модель для реализации: связная сеть полей и проводников, множество различных вычислительных типов в компоненте. Один тип — обычный режим; два — синтез; три или больше — вся вовлечённая сеть становится VOID, включая проводники. Это не случайность: оценка «95% пересечений» в обсуждении означает практическую опасность, а не вероятность срабатывания.

Пример: 9 клеток OBSERVE (в старой геометрии примера), 6 CHOOSE и 7 CONNECT дают 15 синтезированных клеток и 7 клеток провода. Подключение ещё 3 клеток RUNTIME превращает все 25 различных клеток в VOID. В текущей геометрии OBSERVE физически занимает одну клетку, поэтому его информационный охват не считается в этой сумме; пример иллюстрирует именно каскад.

Пересечение CONNECT с CONNECT объединяет сети. Если объединение содержит 3+ типов, обе сети выгорают. Если объединение содержит не более двух типов, правило перегрузки само по себе не выполняется. Нет автоматических мостов между пересекающимися проводами. DISSOLVE может разорвать сеть до перегрузки; после перегрузки простое разъединение не восстанавливает поля.

## VOID
Не мутирует, не проводит, не синтезируется, не вычисляется. Только DISSOLVE очищает его; очистка не восстанавливает старую конструкцию. Конкретные последствия частичной очистки TBD.

## Матрица (эффекты пока не определены)

- ENCODE × CHOOSE / CYCLE / LOGIC / RUNTIME
- CHOOSE × CYCLE / LOGIC / RUNTIME
- CYCLE × LOGIC / RUNTIME
- LOGIC × RUNTIME

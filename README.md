# DEEP//ORAL: 1987

> Визуальная новелла, пародирующая гача-игры, с самостоятельной пошаговой вычислительной песочницей RESONANCE.

**Статус: предпроизводство, 26 ноября 2026.** Игровой билд пока отсутствует.

Игра всерьёз относится к собственному абсурдному миру. Сюжет строится вокруг академии и её доктрины, а операции представлены абстрактной вычислительной механикой. Сам сексуальный процесс не показывается. Юмор возникает из контраста между предпосылкой и серьёзностью исполнения.

## Состав игры

- Визуальная новелла: пять сюжетных сезонов, персонажи, выбор пола протагониста и различающиеся ветки.
- **RESONANCE**: пошаговое проектирование вычислительных полей на изменяющейся троичной сетке. Карты аргументов, операторы, синтезы, маршрутизация CONNECT, экономика PU.
- **ProcessCards**: кандидат на отдельную факультативную карточную игру; не смешивать с RESONANCE.
- Коллекция из 22 персонажных козырей (отдельная от числовых карт RESONANCE).
- Иллюстрации, музыка и, по возможности, синтетическая озвучка с постоянными голосами персонажей.

## Распространение

Полностью бесплатная игра. Без платной гачи, доната и платных карт. Предпочтительное направление — Godot с веб-экспортом, локальными сохранениями и возможной публикацией на GitHub Pages. Нативные бесплатные сборки — альтернатива. Лицензия исходников и ресурсов пока не выбрана; публичный репозиторий не означает автоматически свободную лицензию.
